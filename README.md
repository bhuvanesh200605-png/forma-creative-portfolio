# FORMA — Creative Studio Portfolio Concept (Enhanced)

A responsive front-end portfolio concept for a fictional creative studio. It demonstrates visual identity, campaign art direction, digital product UI, UX case-study storytelling, responsive layout, and interaction design.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Click any project title to open its case study in `project.html`.
4. Toggle the theme button to switch between light and dark modes.
5. Test the project filters and contact form.

Google Fonts are optional; the site uses system fallbacks if the font CDN is unavailable.

## Working interactions
- Animated abstract hero artwork (CSS motion, with reduced-motion support)
- Light/dark theme toggle
- Responsive navigation menu
- Project category filters (All / Brand identity / Digital / Motion & campaign)
- Four dynamic project case-study pages rendered from the `project.html?project=...` query
- Contact form validation for name, email, project type, and message
- Accessible form feedback and keyboard-focusable controls
- Responsive desktop/tablet/mobile layouts

## Important notes
- All portfolio projects are fictional concepts created for this demo.
- The contact form validates locally only; it does not transmit or store data.
- This is a front-end project, not a production agency website. Review and personalize the content before presenting it as your own.
- No Adobe or Figma proficiency is implied by this code project. Practice those tools separately and list them only when you can confidently discuss your work.

## Suggested case-study explanation
**Challenge:** Create a single digital experience that communicates a creative studio's services while showcasing varied visual directions.
**Approach:** Establish a bold typographic system, a warm neutral base, orange accents, custom CSS artwork, clear content hierarchy, category filtering, theme switching, and project case studies.
**Design decisions:** Large editorial headlines create confidence; mono labels add a production/editorial tone; project-specific palettes distinguish concepts; responsive breakpoints preserve readability.
**Next improvements:** Add Figma wireframes, usability-test notes, real video/GIF exports, a real contact backend, and original case-study imagery.
